# Онбординг отдела продаж

Бот остаётся HR-ассистентом Impact Admissions. Дополнительно он ведёт новых сотрудников отдела продаж (ОП).

Остальные модули не сужать до ОП: поздравления, сборы и анонсы по-прежнему для компании. Анкета, запись в Notion и файлы обучения — только для нового сотрудника ОП.

## После /start

Приветствие на «ты» от имени HR-бота Impact Admissions. Кнопки:

- «Я новый в отделе продаж»
- «Я уже в команде»

Уже в команде: привязать Telegram ID к сотруднику или приглашению, без анкеты и без Notion.

Новый сотрудник ОП: анкета по одному вопросу, кнопки где уместно.

Поля анкеты:

- ФИО
- Имя для обращения
- Телефон
- Дата рождения
- Должность
- Дата выхода
- Город

Подразделение проставляется как отдел продаж. Статус — активный, когда анкета завершена. Согласие на публичное поздравление спросить отдельным вопросом, по умолчанию не включать молча.

## Куда писать

- Своя база сотрудников — всегда.
- Notion — отдельно, те же поля плюс Telegram ID, username и время заполнения. Лишние кадровые поля в Notion не отправлять.
- Секрет: Runtime Secret `NOTION_API_KEY`. ID базы — настройка организации, не секрет. Текущий ID: `40159421a41f80c1bfd5ce5b06de3213`.
- Без ключа или без ID базы анкета сохраняется в своей базе, Notion пропускается, ошибка пишется в журнал. Тестовый адаптер в тестах, без сети.
- Повторный Start не создаёт вторую запись того же Telegram ID.

## Обучение

После успешной анкеты бот отправляет пакет файлов обучения ОП в личку.

Файлов пока нет. Пока пакет пуст, бот говорит, что материалы ещё не загружены, и не выдумывает содержимое.

Файлы хранить в настройках онбординга, не зашивать тексты обучения в код.
